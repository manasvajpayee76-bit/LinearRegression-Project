# Linear Regression Exam Score Predictor

This project uses Linear Regression to predict student exam scores (`Exam_Score`) based on the number of hours studied (`Hours_Studied`). It trains a model, makes predictions, calculates the Mean Squared Error (MSE), and generates a visualization plot.

## Files Included:
- `main.py`: Python script containing the linear regression logic, prediction, evaluation, and plotting.
- `students.csv`: Sample dataset containing hours studied and corresponding exam scores.
- `regression_plot.png`: Generated plot showing the regression line and actual data points.

## Requirements:
Make sure you have the following Python libraries installed:
- pandas
- scikit-learn
- matplotlib

## How to Run:
Execute the main script using the command:
```bash
python main.py
